Прошивка термометра

Первая установка и обновление по USB — без дополнительных программ.

Обновление сохраняет настройки и Zigbee-привязку. Поддерживается ESP32-C6 SuperMini с прошивкой этого проекта и совместимой разметкой памяти.

Первая установка полностью очищает плату. Прежняя прошивка, настройки и привязка будут удалены.

Сначала отключите термометр в диагностике и закройте монитор VS Code. Во время записи не отключайте питание.

Плата не подключается?

Используйте USB-кабель с передачей данных. Для ручного режима загрузки удерживайте BOOT, нажмите и отпустите RESET, затем отпустите BOOT и повторите подключение.
