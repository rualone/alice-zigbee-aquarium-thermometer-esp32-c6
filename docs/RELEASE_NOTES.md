# v0.1.0-beta.1 — первый тестовый выпуск

Аквариумный термометр на ESP32-C6 SuperMini и DS18B20 с прямым подключением
к «Дому с Алисой» через Zigbee. Работа предыдущей сборки подтверждена
со Станцией Миди.

## Возможности

- Один DS18B20 на GPIO4, питание 3,3 В и подтяжка 4,7 кОм.
- Контрольная сумма измерений и восстановление шины после ошибки.
- Отправка при изменении от 0,2 °C или раз в минуту.
- Светодиодная индикация и сброс привязки кнопкой BOOT.
- Настройки через menuconfig, русская документация.

## Установка

Скачайте **Source code (zip)** или клонируйте тег `v0.1.0-beta.1`.
Откройте проект в окружении ESP-IDF 6.1 и выполните из корня:

```sh
idf.py set-target esp32c6
idf.py build
idf.py -p PORT flash monitor
```

Замените PORT на порт своей платы. Подключение щупа и сопряжение с Алисой
описаны в README. В релиз входят исходники; готовые бинарные прошивки
не прикладываются.

## Ограничения

Это предварительный выпуск независимого DIY-проекта. Проверенная модель
хаба — Станция Миди; другие модели не проверены. Светодиод рассчитан на
обычный активный низким уровнем GPIO15, варианты плат могут отличаться.
Локальная индикация не подтверждает доставку показаний Алисе. Отображение
ошибки щупа и восстановление после сбоев требуют дополнительных проверок.
Текущая сборка проверена компиляцией; изменения после подготовки репозитория
ещё не проверены на оборудовании. Полный список — docs/VALIDATION.md.
