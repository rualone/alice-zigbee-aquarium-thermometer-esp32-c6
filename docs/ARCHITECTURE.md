## USB-протокол

USB Serial/JTAG, 115200 бод. Команды завершаются LF; ответы — отдельные строки JSON. ESP_LOG между ответами игнорируется. Повреждённые и переполненные команды не исполняются.

| Команда | Ответ |
| --- | --- |
| `AQ1 SNAPSHOT` | `@AQ1 {…}` — снимок состояния. |
| `AQ1 SETTINGS {…}` | `@AQSET {"ok":true/false}`, затем снимок. |
| `AQ1 RESET_SETTINGS` | Такой же ACK и снимок после сброса. |

Страница опрашивает состояние раз в две секунды. При сохранении опрос приостанавливается: без идентификаторов запросов допустима только одна ожидающая ACK команда. `ok:true` означает успешное сохранение; тайм-аут не доказывает отказ записи.

### Снимок

`device` равен `alice-zigbee-aquarium-thermometer`, `protocol` — 1, `type` — `snapshot`.

| Поля | Значение |
| --- | --- |
| `firmware`, `uptime_ms`, `reset_reason` | Версия, время работы и причина запуска ESP-IDF. |
| `probe`, `temperature_c`, `measurement_age_ms` | `waiting`/`ok`/`error`, температура или null, возраст измерения или null. |
| `raw_temperature_c`, `applied_offset_centi` | Исходное измерение или null и применённая поправка. |
| `sample_interval_ms`, `probe_errors`, `report_failures` | Пауза измерений и счётчики ошибок. |
| `zigbee_joined`, `zigbee` | Локальное участие в сети; объект `{state, reason, state_age_ms}` проверки координатора. |
| `report_age_ms` | Возраст последнего отчёта в очереди или null. |
| `events` | До 64 записей `{seq, ms, message}`; время в миллисекундах от запуска. |
| `settings`, `settings_reset`, `theme_settings` | Значения настроек и поддержка дополнительных команд. |
| `update_pending` | Проверка первого запуска ещё не завершена. |

Проверки версии и наличия полей сохраняют совместимость с ранними сборками. Участие в сети, ответ координатора и доставка температуры — разные факты. Для проверки координатора отводится 20 секунд; следующая попытка начинается через 10 секунд после завершения предыдущей. После двух неудач подряд фиксируется отсутствие ответа.

### Настройки

Обязательные поля `AQ1 SETTINGS`: `brightness` (0–255), `sample_seconds` (2–3600), `report_seconds` (5–3600), `delta_centi` (1–1000). Необязательные: `offset_centi` (−500…500, кратно 10) и `theme` (0–3). Все значения целые; неизвестные и повторные ключи отвергаются. Отсутствующие необязательные поля сохраняют текущие значения.

Темы: 0 — «Травник», 1 — «Морской», 2 — «Биотоп», 3 — «Риф»; идентификаторы стабильны.

## Хранение

В NVS-пространстве `aq_settings` ключ `config` содержит запись схемы 2 с измерительными параметрами; схема 1 читается с нулевой поправкой. Тема хранится отдельным ключом `theme`. Номер схемы не связан с номером релиза. Неизвестный формат защищён от перезаписи; отсутствующие значения получают настройки сборки.

Записи параметров и темы независимы, общей транзакции нет. Откат приложения не восстанавливает произвольно изменённую NVS. Копия в RAM обновляется после успешного сохранения и защищена mutex.
