- [x] На плате: переход 0.2 → 0.7 через сайт подтверждён пользователем; по USB проверены версия 0.7, завершённая проверка запуска, измерения и ответ координатора Zigbee.

- [x] На плате: 0.7 → 0.7.1 → 0.7.2 через сайт; служебные записи подтвердили ota_1 → ota_0 → ota_1. Обе сборки подтвердили запуск, изменённые настройки сохранились, щуп и хаб работают.
- [x] На плате: USB отключён на 68% записи 0.7.4; после подключения работает прежняя 0.7.2. По USB подтверждены сохранение изменённых настроек, измерения и ответ хаба. Повторная установка 0.7.4 завершилась успешно; запуск подтверждён, настройки сохранены.

При переходе со старой разметки не отключайте питание: запись загрузчика и таблицы разделов не имеет резервной копии. Испытание обрыва проводите только после перехода на 0.7.

Проверка без хаба выявила зависимость запуска щупа от успешного восстановления Zigbee: сборка 0.7.5 откатилась, 0.7.4 осталась без измерений. Запуск локальных задач перенесён до восстановления сети; повторное испытание 0.7.7 без хаба успешно, подтверждено пользователем и USB-диагностикой.

После испытаний установлена итоговая исправленная 0.7; исходные настройки восстановлены. По USB подтверждены версия 0.7, завершённая проверка запуска, исправный щуп и ответ хаба. Локальный установщик возвращён к пакету 0.7.
