## Проверка 0.2.0: RGB-индикация

- [ ] После сопряжения остаётся только температурная карточка.
- [ ] При поиске сети GPIO15 быстро мигает, GPIO8 жёлтый.
- [ ] После подключения с исправным щупом GPIO15 выключен, GPIO8 зелёный.
- [ ] Ошибка щупа: GPIO15 выключен, GPIO8 красный.
- [ ] Удержание BOOT пять секунд: GPIO15 выключен, GPIO8 синий.
- [ ] Отпускание BOOT запускает повторное сопряжение.
- [ ] После перезапуска RGB не зависит от прежнего сохранённого On/Off.
- [ ] Температура продолжает обновляться, RGB не мешает шине DS18B20.
