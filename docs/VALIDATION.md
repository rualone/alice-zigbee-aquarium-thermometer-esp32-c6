# Проверка

Проверено на ESP32-C6 SuperMini с DS18B20 и Станцией Миди.

## Версия 0.1

- [x] Сборка и прошивка платы
- [x] Сопряжение с Миди
- [x] Без щупа: повторяемый NOT_FOUND без зависания RMT
- [x] Чистая сборка текущих исходников с ESP-IDF 6.1
- [x] Реальные измерения и прогрев щупа рукой
- [x] Отключение и возврат щупа
- [x] Перезапуск платы с сохранением привязки
- [x] Перезапуск Миди и восстановление передачи
- [x] Сброс BOOT и повторное сопряжение
- [x] Непрерывная работа 24 часа

## Версия 0.2

- [x] После сопряжения остаётся только температурная карточка.

- [x] После подключения с исправным щупом GPIO15 выключен, GPIO8 зелёный.
- [x] Ошибка щупа: GPIO15 выключен, GPIO8 красный.

- [x] Прошивка с USB-протоколом AQ1 собирается с ESP-IDF 6.1.
- [x] Автоматические проверки веб-протокола, отчёта и имитации USB.
- [x] Реальное подключение браузера к плате после обновления прошивки.
- [x] Отключение кабеля, ошибка щупа и занятый порт на реальном оборудовании.
- [x] Экспорт отчёта и параллельная работа Zigbee.
