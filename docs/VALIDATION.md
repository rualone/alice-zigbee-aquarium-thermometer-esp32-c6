# Проверка

Владелец подтвердил подключение к Станции Миди и работу собранного датчика.
Это пользовательская проверка, не сертификация. После подготовки репозитория
код изменён; новую сборку нужно отдельно проверить на плате.

- [x] Предыдущая версия собиралась и прошивалась
- [x] Предыдущая версия сопрягалась с Миди
- [x] Без щупа: повторяемый NOT_FOUND без зависания RMT
- [x] Чистая сборка текущих исходников с ESP-IDF 6.1
- [ ] Новая сборка: реальные измерения и прогрев рукой
- [ ] Отключение и возврат щупа
- [ ] Ошибка щупа в приложении вместо старого показания
- [ ] Перезапуск платы с сохранением привязки
- [ ] Перезапуск Миди и восстановление передачи
- [ ] Сброс BOOT и повторное сопряжение
- [ ] Непрерывная работа 24 часа

Индикатор показывает локальное состояние прошивки, не подтверждение доставки.
Статус сети после перезапуска не проверяет доступность координатора.
