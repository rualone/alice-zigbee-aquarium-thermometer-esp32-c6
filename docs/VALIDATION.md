# Проверка

## Автоматические проверки

- [x] Сборка прошивки с ESP-IDF 6.1.
- [x] Проверки C-кода: чтение старых форматов NVS, диапазоны, ошибки хранения, сброс, тема и защита неизвестных схем.
- [x] Проверки первого запуска: подтверждение готовности задач и тайм-аут с откатом.
- [x] Автомат Zigbee: тайм-ауты, повторы, устаревшие ответы и смена сети.
- [x] Веб-протокол, подключение, черновики настроек, темы, анимации окон и числовое сравнение версий.
- [x] Установщик: проверка пакета, адресов, целостности, выбора раздела и имитация прерывания записи.

## Аппаратные испытания при разработке

Сценарии проверялись на ESP32-C6 SuperMini, DS18B20 и Станции Миди. Эти результаты относятся к разработанным механизмам; они не заменяют финальный прогон конкретного бинарного файла 1.0.

- [x] Сопряжение, измерение температуры, восстановление щупа и сети после отключения.
- [x] Сохранение настроек после перезапуска и перепрошивки, сброс без удаления Zigbee-привязки.
- [x] Установка через браузер, переход со старой разметки, чередование разделов.
- [x] Обрыв USB на 68% записи, запуск предыдущего приложения и успешное повторное обновление.
- [x] Намеренный сбой первого запуска с автоматическим откатом.
- [x] Первый запуск без хаба и без щупа не вызывает откат; найденная зависимость измерений от восстановления сети исправлена.
- [x] Сброс оформления, обновление полей, сохранение привязки и темы по умолчанию после перезапуска подтверждены пользователем.

## Финальная проверка 1.0

- [ ] Установить собранную 1.0 через браузер, проверить номер версии, температуру и ответ хаба.
- [ ] Проверить сохранённые параметры, выбор и отмену темы, отключение USB и повторное подключение.
- [ ] Проверить установку с нуля на запасной плате или с явным согласием на удаление данных.

Не отключайте питание при первой замене загрузчика и таблицы разделов: у этих областей нет резервной копии. Полное стирание памяти не требуется для обычного обновления.
