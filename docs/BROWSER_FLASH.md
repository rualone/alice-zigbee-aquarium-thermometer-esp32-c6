# Прошивка через браузер

Откройте [установщик](https://rualone.github.io/alice-zigbee-aquarium-thermometer-esp32-c6/install.html) в Chrome или Edge на компьютере. Подключите ESP32-C6 SuperMini кабелем с передачей данных и отключите её от страницы диагностики и монитора VS Code.

- **Первая установка** очищает плату и записывает загрузчик, разметку и приложение. Требует явного подтверждения удаления прежних данных.
- **Обновить термометр** проверяет установленный проект, версию и совпадение разметки. Записывает только приложение, сохраняя настройки и Zigbee-привязку. Несовместимая разметка и понижение версии блокируются.

Не отключайте питание во время записи. После успешной проверки окно закрывается. Отключите USB-кабель и подключите его снова, затем нажмите «Подключить термометр». Автоматическое подключение отключено из-за наблюдавшихся падений браузера. Если автоматическое подключение не работает, удерживайте BOOT, нажмите и отпустите RESET, отпустите BOOT и повторите выбор платы. При прерывании записи повторите обновление; настройки могут сохраниться, но приложение до повторной записи может не запускаться.

Файлы сборки загружаются с того же сайта и проверяются по SHA-256. Загрузчик esptool-js 0.7.1 загружается с esm.sh при начале установки; для этого нужен интернет. Пакет включает только ESP32-C6.

Для локального запуска сначала соберите проект, затем выполните `python3 scripts/package_web_firmware.py` и запустите сервер страницы. GitHub Pages собирает и упаковывает прошивку автоматически из того же коммита, что и страницу.

Полный цикл обновления через браузер подтверждён пользователем на ESP32-C6, включая автоматическое переподключение без отключения USB. Первую установку на пустую плату ещё нужно проверить.

Контрольное испытание загрузчика 0.7.1: запись через Uint8Array, проверка MD5 и закрытие порта. Программный сброс и автоматическое подключение временно отключены для изоляции нативного падения Chromium. После записи требуется переподключить USB. Стабильность новой последовательности на оборудовании ещё проверяется.
